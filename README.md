# QISWAH.id

QISWAH.id Tour & Travel Umrah Haji — production-ready demo starter.

## Run

```bash
npm install
npm start
```

## API

- `GET /api/health`
- `GET /api/packages`
- `POST /api/leads`
- `POST /api/chat`

## Deployment

Configured for Vercel with `vercel.json`. For production database integration, set `DATABASE_URL` to the provisioned Neon PostgreSQL connection string and add server-side database migrations.
